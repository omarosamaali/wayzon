# Wayzon — Project Handover Document

## Project Overview
Wayzon is a SaaS WhatsApp bot for Salla (Saudi e-commerce platform) stores.
It auto-replies to customer WhatsApp messages, handles order status queries, and product searches.

## Salla Integration

### OAuth App Settings (Salla Partners Dashboard)
- **App Type:** Private or Public
- **Redirect URI:** `https://yourdomain.com/salla/callback`
- **Webhook URL:** `https://yourdomain.com/salla/webhook`
- **Required Scopes:** `offline_access`

### Webhook Events to Subscribe
| Event | Handler |
|-------|---------|
| app.store.authorize | Saves/updates store tokens |
| order.created | Saves order + sends WhatsApp |
| order.status.updated | Updates order status + sends WhatsApp |
| order.completed | Activates plan payment |
| app.subscription.created | Creates/updates user plan |
| app.subscription.updated | Updates user plan |
| communication.whatsapp.send | Sends WhatsApp via our service |

## Bot Logic

### Message Handling Priority
1. **FAQ match** → Direct reply from store config (no AI)
2. **Order number detected** → Fetch from DB or Salla API directly (no AI)
3. **Order keywords** (وين طلبي, شحن, توصيل) → Ask for order number (no AI)
4. **Product keywords** (سعر, بكم, متوفر) → Search Salla products API (no AI)
5. **Everything else** → GPT-4o-mini (AI)

### AI Cost Controls
- Model: `gpt-4o-mini` (hardcoded, cannot be changed)
- History: 8 messages max per conversation
- Max tokens: 200 per response

## Deployment Steps (after domain change)

1. Update `.env` → `APP_URL=https://newdomain.com`
2. Update `.env` → `SALLA_REDIRECT_URI=https://newdomain.com/salla/callback`
3. Update Salla Partners Dashboard → Redirect URI + Webhook URL
4. Run: `php artisan config:clear && php artisan route:clear`
5. Restart WhatsApp service: `pm2 restart whatsapp-service`

## Common Issues & Fixes

| Issue | Fix |
|-------|-----|
| pm2 not found | Use full path: `/root/.nvm/versions/node/$(ls /root/.nvm/versions/node)/bin/pm2` |
| 500 error on site | Check `.env` syntax — spaces in values must be quoted |
| Bot not responding | `pm2 restart whatsapp-service` |
| Email not sending | Check MAIL_SCHEME= (must be empty for port 587) |
| WhatsApp disconnected | Re-scan QR or use pairing code from dashboard |

## Security Notes

- Tokens stored in `salla_stores` table — encrypted at rest
- Access tokens auto-refresh via `SallaTokenService` before expiry
- Admin guard checks current authenticated user email only
- Internal API protected by secret key header
- All passwords hashed with bcrypt
